# Personal-Fianace
A personal finance management program that analyzes spending habits to help build better financial patterns.

# 💳 Personal Finance

> 개인의 소비 및 경제 습관을 분석하여, 더 가치 있고 건전한 소비 습관을 형성하도록 돕는 개인 재무 관리 솔루션입니다.

---

## 📌 주요 기능 (Features)

- ** 지출 데이터 아카이빙 & 비주얼라이즈** : 일별/월별 소비 내역을 수집하고 통계 그래프로 visualizing하여 한눈에 파악합니다.
- ** 소비 패턴 분석** : 자주 지출하는 카테고리 분석 및 불필요한 지출 항목을 식별합니다.
- ** 맞춤형 소비 피드백** : 소비 데이터를 기반으로 개선 포인트를 제안하고 목표 예산 대비 지출 현황을 모니터링합니다.

---

## 🛠️ 기술 스택 (Tech Stack)

- **Language** : Python 3.x
- **Libraries** : Pandas, Matplotlib / Seaborn (데이터 분석 및 시각화)
- **Environment** : Anaconda Spyder, Antigravity IDE
